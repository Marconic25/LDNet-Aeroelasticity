# LDNet-Aeroelasticity

A Latent Dynamics Network (LDNet) learns the aerodynamic loads of a two-degree-of-freedom
airfoil with a trailing-edge flap from partitioned fluid-structure simulations in OpenFOAM,
and is the internal model of a preview model predictive controller (MPC) for gust load
alleviation. Each test case is a self-contained script in `src/`, sharing the libraries
`utils.py` and `optimization.py`.

The repository holds code only. The datasets are generated by the scripts of `fom/`; the
control LDNet used by every closed-loop result is in `models/control_ldnet/`.

## Structure

    src/
      utils.py          normalisation, resampling and loading of the datasets
      optimization.py   training by Adam and BFGS, with the minimum on the validation set
      aeroelastic.py    structure, control LDNet, preview MPC, lidar, closed loop, linear model
      TestCase_N.py     test cases, run from src/
    models/
      control_ldnet/    control LDNet of the closed-loop results
      linear_model.json coefficients of the linear unsteady model, written by TestCase_9.py
    fom/                full-order model: OpenFOAM case, mesh motion, co-simulation, campaign
    validation/         numerical verification of the full-order model

## Test cases

Each script runs from `src/` with `python TestCase_N.py`, and prints its results.

| Script | Content |
|---|---|
| `TestCase_1.py` | input signals of the load LDNet |
| `TestCase_2.py` | latent-state dimension |
| `TestCase_3.py` | network depth |
| `TestCase_4.py` | reconstruction of the velocity and pressure fields |
| `TestCase_5.py` | control LDNet, teacher forcing followed by closed-loop rollout |
| `TestCase_6.py` | closed loop on two reference gusts, cost per simulated second |
| `TestCase_7.py` | eighteen discrete gusts and their effort weight R* |
| `TestCase_8.py` | lidar noise, bias and time shift on the gust W0 = 10 m/s, Tg = 0.4 s |
| `TestCase_9.py` | comparison with a linear unsteady model |

TestCase_1–5 train networks from a random initialisation, and the trained models change with
the seed and the hardware: TestCase_5 saves its model in `models/TestCase_5/` and does not
replace `models/control_ldnet/`. TestCase_6–9 start from `models/control_ldnet/` and return
the closed-loop results.

## Full-order model

`fom/` needs OpenFOAM v7 and the mesh-motion library of `fom/meshMotion/`:

    cd fom/meshMotion && wmake libso && cd ..
    ./Allrun run                          # mesh, RANS at trim, co-simulation to the checkpoint at 3 s
    python campaign.py campaign.csv       # Latin hypercube of families A, B and C
    cp -r run/case run/sim_A_000_train    # every run of campaign.csv, in a copy of the case
    python cosim_driver.py --case run/sim_A_000_train <options of the run in campaign.csv>
    python build_dataset.py run/ ../data/

The closed loop on the full-order model runs the same driver with the MPC of `mpc_server.py`:

    python cosim_driver.py --case run/gust --from-checkpoint --gust 20 0.7 --mpc 1e-4 --d-alpha 19.8

## Data

The test cases read `data/` at the root of the repository:

- `GLA_{train,valid,test}.h5`, from `fom/build_dataset.py`: `points` [1 x 2], `times` [T],
  `input_parameters` [N x 1] (U_inf), `input_signals` [N x T x 6] (h, dh/dt, alpha,
  dalpha/dt, delta, W), `output_signals` [N x T x 1 x 2] (F_y, M_z), `sim_families` [N];
- `FIELDS_{train,valid,test}.h5`: `points` [P x 2], `times`, `input_parameters`,
  `input_signals` as above, `output_fields` [N x T x P x 3] (u_x, u_y, p);

## Validation

The scripts of `validation/` run the numerical verification of the full-order model on the folder written by
`fom/Allrun`, and print their results:

| Script | Study |
|---|---|
| `grid_convergence.py run/grid` | RANS at trim on four meshes, Grid Convergence Index |
| `coupling_window.py run/` | flap step with co-simulation windows of 100, 50, 25 and 10 steps |
| `time_step.py run/` | reference gust at fixed step and at maximum Courant number 4, 2 and 1 |
| `energy_balance.py run/<case>` | interface energy balance of a co-simulation run |

## Requirements

Python 3.10 or later with the packages of `requirements.txt`; OpenFOAM v7 for `fom/` and
`validation/`.
